### 问题根源

**预期机制**（我们设计的）：
```
Agent 识别意图 → 加载 rules/offline-detection.md（4KB）
              → 不加载完整 SKILL.md（50KB）
```

**实际机制**（Hermes 行为）：
```
Hermes 匹配 skill → 加载整个 SKILL.md（50KB）
               → 注入到 system_prompt
               → Agent 在 system_prompt 中看到完整内容
```

**结论**：Hermes 的 skill 加载是**全量加载**，不支持部分加载。
